\# Cybersecurity Awareness Bot - Part 2



\## How to Run

1\. Clone this repository

2\. Open CybersecurityChatbotWPF.sln in Visual Studio

3\. Press F5 to run



\## Features Implemented

\- WPF GUI with coloured design and ASCII art

\- Voice greeting on startup (greeting.wav in Audio folder)

\- Keyword recognition: password, phishing, scam, privacy, browsing

\- Random responses using List collections

\- Conversation flow - handles "tell me more", "another tip"

\- Memory system - remembers user name and interests

\- Sentiment detection - responds to worried, curious, frustrated

\- Empathetic responses based on user mood

\- Input validation and error handling

\- Quick topic buttons

\- Clear chat button

\## Technologies
